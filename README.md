# Student Management System - Java

A console-based Java application to manage student records. My first project on GitHub!

## Features
- Add Student (ID, Name, Course)
- View All Students
- Search Student by ID
- Delete Student by ID

## Tech Stack
- Java, VS Code, OOP, ArrayList

## How to Run
javac StudentManagementSystem.java
java StudentManagementSystem
